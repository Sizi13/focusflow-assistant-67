# FocusFlow Assistant (67)

Prompt: AI-Powered Workplace Productivity Assistant

1. Role

Act as a professional software developer, AI engineer, and UI/UX designer.

2. Objective

Build an AI-powered web application that combines a Task Planner / Scheduler, AI Research Assistant, and Interactive AI Chatbot to improve productivity and save time.

3. Context

The application is designed for students, employees, entrepreneurs, and professionals who need help organizing tasks, researching information, and managing daily work.

4. Requirements

Task Planner / Scheduler: Generate daily schedules, prioritize tasks, track deadlines, and monitor progress.

AI Research Assistant: Research topics, summarize articles, identify key points, and provide insights and recommendations.

AI Chatbot: Handle user prompts, answer questions, support conversations, and provide helpful responses.

Dashboard: Integrate all three tools into one user-friendly interface.

Technical Features: Ensure responsive design, secure AI integration, data storage, and functional buttons.

5. Output

Build a fully functional, responsive web application with a professional dashboard, easy navigation, working AI features, and a clean interface suitable for desktop and mobile devices.
